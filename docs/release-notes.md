**Install**

1. Download the zip below and unzip it.
2. Move `ClipTyper.app` to the Applications folder.
3. The app is not notarized by Apple, so run this once in Terminal:
   ```
   xattr -dr com.apple.quarantine /Applications/ClipTyper.app
   ```
4. Open ClipTyper and allow it under System Settings > Privacy & Security > Accessibility.

Runs on Apple silicon and Intel Macs with macOS 13 or newer.

When updating from an earlier version, macOS asks for the Accessibility permission again.
